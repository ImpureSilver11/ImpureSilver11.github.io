# 文章スタイルガイド

このブログで公開する文章の書き方。ブログ記事（`posts/`）が主な対象だが、README・告知文・PR 説明など、**人が読む日本語の文章すべて**に適用する。

記事を書くときは `/new-post` スキルからこのファイルを参照する。

---

## 口調・文体

- です・ます調とだ・である調を自然に混在させる。どちらかに統一しない
- 「〜なぁと思ってます」「〜なのかなと思ってます」など柔らかい推量表現を使う
- 「正直」「めっちゃ」「つらかった」など感情を素直に出す
- 「だけど」「〜なんだけど」のような逆接・マイナス寄りの表現を時折混ぜる。前向きな話だけで埋めない
- 友達に話しかけるようなトーンで書く

### 三点リーダ

マイナスな感情で段落や文を締めるときに付ける（例: 「つらかった…」「しんどかった…」「これは効かなかった…」）。

- **`…。` と句点を重ねない。** 三点リーダで終わるなら `…` だけ、句点で終わるなら `。` だけ。どちらか一方のみ使う
- 使いすぎると重いので、**記事全体で3〜5箇所程度**に抑える。マイナスな文が続くときも全部に付けず、一番効かせたい箇所だけに使う

---

## AIっぽさを消す（最優先で守る）

「AIが書いた文章」の指紋は、語彙より**構造**に強く出る。両方潰す。

### 語彙・構文の禁止リスト

使ったら書き直す。

| 分類 | 禁止する表現 |
|---|---|
| 予告と要約 | 「本記事では」「この記事では」「〜について解説します」「まとめると」「つまり〜ということです」 |
| 空虚な評価語 | 「非常に」「極めて」「まさに」「重要です」「便利です」「効率的」「最適な」「強力な」 |
| 硬い名詞化 | 「〜の観点から」「〜という点で」「〜を実現する」「〜を活用する」「〜を担保する」、可読性・拡張性・保守性の並列 |
| 過剰ヘッジ | 「〜ではないでしょうか」「〜と言えるでしょう」の連発 |
| 教師トーン | 「〜しましょう」「ぜひ」「いかがでしょうか」「注意が必要です」 |
| 出典なき一般化 | 「一般的に」「〜と言われています」「多くの場合」 |
| 冗長形 | 「〜することができます」→「〜できます」、不要な「〜になります」→「〜です」 |
| 定型見出し | 「はじめに」「おわりに」「まとめ」「メリット・デメリット」「注意点」 |
| 対称的な3点列挙 | 「速く、安全に、そして安く」のような形 |

記号のクセ:

- `——`（em dash）は使わない。句点・読点・カッコで書き換える
- 絵文字見出し禁止
- 「**用語**：説明」形式の羅列禁止（箇条書きや段落の頭を太字で揃えるのもこれに含む）
- 太字は1セクション2箇所まで（`<Callout>` の中は別カウント）

### 構造の禁止リスト

語彙より重要。

- セクションの長さを揃えない。6段落のセクションと2段落のセクションが混在していい
- セクション冒頭の「これから話すこと」と末尾の「いまの要約」を置かない（サンドイッチ構造禁止）
- 網羅しようとしない。片方だけ厚く書いて、もう片方は「触ってないので分からない」で済ませる
- すべての主張に理由を付けない。理由なしで言い切る文を混ぜる
- 箇条書きの項目を同じ長さ・同じ構文で揃えない。1項目だけ長くていい
- 疑問を投げてすぐ自分で答えない
- 結論が出ていない話題を1つは残す（「ここはまだ分かってない」で終わる段落を作る）
- 記事全体で1回だけ脱線して戻る。「話が逸れた」と自分で書いてよい
- 読者の理解度に配慮する文（「難しいと感じた方は」）を書かない

### 具体性のルール

- 数字・バージョン・エラーメッセージの原文・所要時間・固有名詞を入れる。「かなり遅い」ではなく「3.2秒かかってた」
- **知らない事実は作らない。** 分からない箇所は本人に聞く。聞けなかった箇所は `<!-- TODO: 実際の数値 -->` を残す。捏造は禁止
- 具体が書けないトピックは、一般論で埋めるのではなく削る

### やりすぎ注意

脱線・未解決・言い切りは各1〜2箇所で十分。多用すると「わざと崩した文」になって、それもそれで機械っぽい。

---

## 書いてはいけないこと

- 「本記事では〜を解説します」のような堅いビジネス文
- 箇条書きの羅列だけで終わるセクション
- 「以上です」「まとめると」で唐突に終わる締め
- 「ここは大事」「ここが一番話したかったこと」など、重要度を高く見せる前振り（絶対に書かない）

## 自己チェック

書き終えたら必ず実行する。

### 機械チェック

```bash
grep -nE '本記事|この記事では|解説します|まとめると|非常に|極めて|まさに|重要です|便利です|効率的|最適な|強力な|の観点|という点で|を実現|を活用|を担保|ではないでしょうか|と言えるでしょう|しましょう|ぜひ|いかがでしょうか|注意が必要|一般的に|と言われて|多くの場合|することができ|——|…。' {対象ファイル}
```

ヒットが1件でもあれば書き直して、ゼロになるまで繰り返す。

### 目視チェック

- [ ] セクションの長さがバラついているか（全部同じなら削るか足す）
- [ ] 予告→本文→要約のサンドイッチになっていないか
- [ ] 結論が出ていない話題が1つ以上あるか
- [ ] 脱線が1箇所あるか
- [ ] 数字・固有名詞・エラーメッセージの原文が入っているか
- [ ] 箇条書きの項目の長さが不均等か
- [ ] 見出しが「はじめに」「おわりに」「まとめ」になっていないか
- [ ] 太字が1セクション2箇所以内か
- [ ] 実体験の記述が、本人が実際に語った内容だけで構成されているか（捏造ゼロ）
